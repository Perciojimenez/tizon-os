Instalar Tizón OS en tu iPhone - Paso a Paso
⚠️ MUY IMPORTANTE - Lee Esto Primero

El servidor de Expo debe ejecutarse en TU COMPUTADORA (Mac o PC), NO en este entorno de desarrollo.

Tu iPhone se conectará a tu computadora a través de WiFi.

1
Descargar Expo Go en tu iPhone

En tu iPhone:

  • 📱 Abre la app App Store
  • 🔍 Busca "Expo Go"
  • ⬇️ Toca el botón "Obtener" para instalar
  • ✅ Espera a que se instale (es gratis, ~75 MB)
🚀
Expo Go

Developer Tools

OBTENER

Así se ve en el App Store ☝️

2
Preparar el Proyecto en tu Computadora

En tu Mac o PC:

Opción A: Clonar desde GitHub (Recomendado)

Abre Terminal (Mac) o Command Prompt (Windows) y ejecuta:

# 1. Clona el repositorio git clone https://github.com/Perciojimenez/tizon-os.git # 2. Entra a la carpeta mobile cd tizon-os/apps/mobile # 3. Instala las dependencias npm install
💡 ¿No tienes Node.js instalado?

Si ves un error "npm: command not found":

  1. Ve a https://nodejs.org/
  2. Descarga la versión LTS (recomendada)
  3. Instala y reinicia la Terminal
  4. Ejecuta de nuevo: npm install

Opción B: Descargar ZIP

Si no tienes Git instalado:

  • Descarga el archivo tizon-os-completo.zip
  • Descomprímelo en tu computadora
  • Abre Terminal y navega a la carpeta
  • Ejecuta npm install
3
Iniciar el Servidor de Expo

En la Terminal, dentro de la carpeta tizon-os/apps/mobile:

npm start

Conectar tu iPhone al Servidor
📡 Requisito Importante

Tu iPhone y tu computadora deben estar en la misma red WiFi.

Verifica que ambos dispositivos estén conectados al mismo router WiFi.

Método 1: Con la Cámara de iOS (Más Fácil) ⭐

  1. 📷 En tu iPhone, abre la app Cámara (la app nativa de iOS)
  2. 📸 Apunta la cámara al código QR que aparece en la Terminal

  4. 👆 Toca la notificación
  5. ⏳ Expo Go se abrirá automáticamente y comenzará a cargar la app

⚠️
Solución de Problemas

❌ "Unable to connect to Metro"

Problema: Tu iPhone no puede conectarse al servidor.

Solución 1: Verifica que iPhone y computadora estén en la misma red WiFi.

Solución 2: Usa el modo túnel (funciona sin estar en la misma red):

npm start -- --tunnel

❌ "Network request failed"

Problema: La app carga pero no se conecta al backend.

Solución: Verifica que el archivo .env exista en apps/mobile/ con:

EXPO_PUBLIC_API_URL=https://tizon-os-production.up.railway.app

Luego reinicia el servidor (Ctrl+C y npm start de nuevo).

❌ La app se ve en blanco

Solución:

  • En la Terminal, presiona r para recargar
  • En el iPhone, agita el teléfono → "Reload"
  • Cierra Expo Go completamente y vuelve a escanear el QR

🎉 ¡Felicidades! Tu sistema Tizón OS está completamente operativo.
