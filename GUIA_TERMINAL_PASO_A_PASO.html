ℹ️ ¿Qué es la Terminal?

La Terminal es como un "chat con tu computadora" donde le das instrucciones escribiendo texto. No te preocupes — solo tienes que copiar y pegar exactamente lo que te muestro aquí.

2
Verifica que Node.js esté instalado 🔍
Node.js es el motor que hace correr la app
1
En la Terminal, copia y pega este comando y presiona Enter:
📋 COPIA ESTE COMANDO
node --version
Terminal — verificando Node.js
percio@MacBook ~ % node --version
v20.11.0 ← Si ves esto, ¡Node está instalado! ✅
⚠️ Si ves un error "command not found"

Node.js no está instalado. Ve a https://nodejs.org/, descarga la versión LTS e instálala. Luego reinicia la Terminal y vuelve a probar.

¿Algo no funciona? Soluciones rápidas
Los 3 problemas más comunes y cómo resolverlos
❌ "Unable to connect to Metro" en el iPhone

Causa: Tu iPhone y tu Mac no están en la misma red WiFi.
Solución: Usa el modo túnel — detén el servidor (Ctrl+C) e inicia con:

📋 Modo Túnel
npx expo start --tunnel

Este modo funciona aunque no estén en la misma WiFi. Tarda un poco más en arrancar.

❌ "npm: command not found"

Causa: Node.js no está instalado.
Solución: Ve a https://nodejs.org → descarga LTS → instala → reinicia Terminal → vuelve al Paso 2.

❌ Pantalla en blanco o app no carga

Solución: En la Terminal, presiona la tecla r para recargar la app.
También puedes agitar el iPhone físicamente → aparece el menú → toca "Reload".

📋 Resumen de Comandos (Para Cuando lo Repitas)

Los 4 comandos en orden
# 1. Ir al escritorio cd ~/Desktop # 2. Entrar a la carpeta (si ya tienes el proyecto) cd tizon-os/apps/mobile # 3. Instalar dependencias (solo la primera vez) npm install # 4. ¡Iniciar la app! npm start

💡 La próxima vez que quieras abrir la app, solo necesitas los pasos 2 y 4 (ya no necesitas instalar de nuevo).
